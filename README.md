# Qari OCR Arabic Deep Dive

Exploring Arabic Optical Character Recognition (OCR) using modern vision-language models and experimentation.

## Overview

This project explores Arabic OCR capabilities using modern AI models, focusing on text recognition, evaluation, and error analysis.

## Objectives

- Explore vision-language models for Arabic OCR.
- Experiment with different model configurations and prompting techniques.
- Evaluate OCR performance using quantitative metrics.
- Investigate common Arabic OCR errors.
- Document experiments and findings.

## Technologies

- Python
- Hugging Face Transformers
- Vision-Language Models
- PyTorch
- Jupyter Notebook
